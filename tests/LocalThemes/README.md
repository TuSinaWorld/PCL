# 本地主题隔离检查

在 Windows / .NET Framework 4.8 环境运行 `./Run.ps1`。不需要启动原版或 fork 启动器，也不读取部署配置、身份信息或凭据。

测试直接编译生产 `ModRecoveredTheme.vb`，并从当前生产源码抽取完整 `MyColor` 类与 `HSL_Change` 处理器。主题模块、测试和滑块处理器使用 Option Strict On；原始 MyColor 保留上游 Option Strict Off 的隐式转换语义，仅在生成副本中去除四处数组行尾注释以兼容 VB 2012，不改数值或逻辑。使用实际 WPF 颜色、渐变画刷、Application 资源以及 PNG 解码器；Settings、窗口容器和 UI 调度队列由隔离夹具提供，不创建或显示启动器窗口。

行为覆盖全部 15 个本地主题、无授权上下文可用性、非法旧设置迁移、自定义参数保存与限幅、同主题刷新、背景开关、主题 12 时间循环、主题 13 静态渐变、工作线程调度、窗口加载前状态与图案资源。另解析真实 XAML 检查全部主题可选且无锁定覆盖层。

编译产物、抽取源码、散列与结果均写入被忽略的 `bin/`。这是模块和处理器隔离验证，不能代替完整 WPF 项目构建或真实界面检查。
